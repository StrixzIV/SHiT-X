# iLeak logos

The supplied PNG originals are preserved in `art/brand/`.

- `ileak-stacked.webp`: stacked droplet and wordmark for the opening quality screen.
- `ileak-wordmark.webp`: horizontal logo for the app header and printable certificate.
- `ileak-mark.webp`: droplet from the horizontal logo for the Start menu, taskbar, agreement, and certificate hologram.
- `favicon.png`: 32 px droplet for browser tabs.
- `apple-touch-icon.png`: 180 px droplet on the app's blue background for home screen bookmarks.

Web assets retain the artwork and transparency, with extra empty space cropped and dimensions reduced for the UI. `BrandLogo.jsx` shares their paths and intrinsic dimensions; `src/index.css` controls their displayed sizes.
